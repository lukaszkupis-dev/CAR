# C.A.R. – Cyfrowy Asystent Rejenta, wersja 2.0

Pliki:
- index.html – cała aplikacja (działa też otwarta lokalnie z dysku)
- manifest.webmanifest, sw.js, ikony – potrzebne do instalacji jako PWA

Publikacja na GitHub Pages:
1. Załóż repozytorium (np. car) i wgraj wszystkie pliki do katalogu głównego.
2. Settings → Pages → Branch: main, folder: / (root) → Save.
3. Po chwili aplikacja jest pod adresem https://<login>.github.io/car/

Instalacja na telefonie: otwórz adres w Chrome (Android) → „Zainstaluj aplikację”,
w Safari (iPhone) → Udostępnij → „Do ekranu początkowego”.

Aktualizacja: podmień index.html i zmień numer w pierwszej linii sw.js (CACHE = 'car-2.0.1' itd.).
